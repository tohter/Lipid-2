# Задача 35 — одна база, универсальный выбор схемы, синонимия как вариант имени

## Почему

Три проблемы, каждая замерена ДО правки:

1. **Универсального выбора схемы нет.** `brain/question.py:answer()` выбирает
   симулятор по КЛЮЧУ словаря (`sims.get("fire")` / `sims.get("soc")`) и по
   списку глаголов прекращения. Имена миров живут в коде, а не в данных.
2. **Сущность и её имя слиты в один ключ.** `entities` индексуются поверх
   леммы (`brain/learner.py:_store_entity`), поэтому «бегемот» и «гиппопотам»
   — два узла с двумя наборами связей. Поле `canonical_id` есть в онтологии
   С САМОГО НАЧАЛА и равно 0 У ВСЕХ 17 узлов живой базы — не заполняется.
3. **SYNONYM_OF = 3 существует в онтологии и не используется НИГДЕ** (grep по
   brain/ core/ ui/ tools/: только тесты SDR, где это пары слов для замера
   близости). Индекс 3 занят специально, чтобы нумерация не сдвигалась.

## Решение (по слову хозяина: сущность ОДНА, имён ДВА)

`SYNONYM_OF` связывает ИМЕНА, а не два узла:
  entities: { "бегемот": {..., "aliases": ["гиппопотам"]} }
  observations: "гиппопотам|SYNONYM_OF|бегемот"
Второго узла не появляется. Канон = ключ `entities`.

Шаги:
  A. `schemes[*].requires` — список нужных ролей. Выбор схемы по ДАННЫМ.
  B. Синонимия: `Learner` перед созданием сущности ищет вариант имени.
  C. Слияние миров в одну базу (пересечения сущностей — пустое множество,
     ключ observations уже канонический `head|REL|tail` → union бесплатен).

ВЫВОДЫ (по цифрам, не по теории):
  1. Бытовые синонимы (кошка/кот, грусть/печаль) ОТДЕЛИМЫ: 0.97–0.98 против
     максимум 0.134 у чужих: между ними пусто, и порог 0.85 стоит там не зря.
     но это ЛЁГКИЕ пары: проверять метод на них одних — самообман.
  2. Книжные синонимы и аббревиатуры (гиппопотам, РФ, ЭВМ) НЕ ОТДЕЛИМЫ:
     0.218 против 0.134 у «стол/небо» — диапазоны перекрываются. Модель
     видела их в разных контекстах, близости нет. ПРИМЕР ХОЗЯИНА — как раз
     этот случай: косинусом «бегемот=гиппопотам» НЕ выводится НИКОГДА.
  3. Косинус не тянет даже морфоварианты: бегемот/бегемота = 0.482. Зато
     stem_key ловит все три морфоварианта — он ДЕТЕРМИНИРОВАН.
  4. Значит СИНОНИМ НЕЛЬЗЯ УГАДАТЬ, его можно только УЗНАТЬ из словаря,
     учителя или явной подсказки в данных — то есть связью SYNONYM_OF В
     ДАННЫХ ровно так, как сказал хозяин. Косинус остаётся только
     предложением-кандидатом (шумно), но НЕ слиянием: ложное слияние двух
     разных сущностей необратимо и отравляет весь граф.
