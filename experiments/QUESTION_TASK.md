# Задача 33: РАЗБОР ВОПРОСА ШАБЛОНАМИ (шаг C из п.29)

## СТАТУС: СДЕЛАНО (см. memory.txt [ЗАДАЧА 33])

## Постановка (ДО правки)

Симуляторы умеют отвечать, но вызов у них РУЧНОЙ:
    sim.why_stopped("пожар")
    sim.why_acted("кошка", "съесть")
Свободный вопрос «Почему кошка съела канарейку?» никто не разбирает. Разрыв C:
между вопросом человека и вызовом симулятора нет звена.

## ПРОВЕРКА ПАМЯТИ ДО ПРАВКИ

  $ grep -rn "def ask\|разбор вопрос" brain/ tools/ -> нет разборщика вопроса.
  Morph (pymorphy3) и split_sentences уже есть -> шаблон + лемма реализуемы
  без LLM. LLM оставляем ТОЛЬКО как fallback, с громким замером где ломается.

## Решения

1. **Разбор — шаблонами, не LLM.** Вопрос режется на леммы тем же
   `core.morph`, что и рассказ (одна морфология на проект, не две).

2. **Тип вопроса** берётся из первого слова/маркера:
   «почему» -> WHY; «что такое / кто такой» -> WHAT; иначе UNKNOWN.

3. **Роли** достаются из падежей (та же логика, что в extract):
   ИМ.п. -> субъект, ВИН.п. без предлога -> объект, глагол -> действие.

4. **Разборщик НЕ отвечает.** Он возвращает Question(type, subject, action,
   objectplot) и «чего не понял». Диспетчер выбирает симулятор.
   Учителя не спрашиваем НИКОГДА (жёсткое правило п.29).

5. **Громкий отказ.** Если тип не распознан или ролей не хватает —
   сказать, ЧЕГО не хватило, а не гадать.

## Критерий готовности

  * `brain/question.py`: `parse_question(text) -> Question`,
    `answer(question, simulators) -> Result`.
  * «Почему прекратился пожар?» -> fire-симулятор -> «потому что вода гасит огонь».
  * «Почему кошка съела канарейку?» -> soc-симулятор -> прежний ответ.
  * Неизвестный тип / пустые роли -> ГРОМКИЙ отказ с указанием причины.
  * Замер: сколько вариантов формулировок разбирается (таблица в тесте).
  * 365+ тестов зелёные.
