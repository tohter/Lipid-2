## ЛОЖЬ ПЕРВОГО ОТЧЁТА — что было сказано и чем это кончилось

### Л1. «Hormones пишут 15 мест, читают 3; в окне декорация» — НЕВЕРНО

`HormoneGate` читает шкалы динамически:

```python
brain/curiosity.py:94    return int(getattr(self._h, name, 0) or 0)
brain/curiosity.py:100       setattr(self._h, name, value)
```

`name` — переменная, AST её не видит. Плюс `brain/lipid2_brain.py:112`:
`HormoneGate(self.hormones)` — **тот же объект**, а не копия. Замер живого
процесса:

```
шлюз поверх объекта мозга?  True     та же шкала, что у цикла: True
кортизол 200 -> must_search()  True        кортизол 0 -> False
пик тревоги + дофамин 255 -> dopamine_ok(True)  False
спокойно    + дофамин 200 -> dopamine_ok(True)  True
```

Значит GUI показывает **те же числа**, по которым шлюз решает «пиши/не
пиши». `core/cortex.py:118-122` прямо запрещает два источника правды
(«GUI показывает одну шкалу, а не две расходящиеся»). Кирпич про гормоны
эту работу сделал; ложной витрины нет; отменяемый мною пункт 1 плана
несуществующий. Моя ссылка на «серотонин/окситоцин» — тоже выдумка: в
`Hormones` три поля.

### Л2. «Мёртвые имена: 20» — столько же, но состав другой

Измерение по одному лишь AST ловит на трёх слепотах, и все три я
прошла по очереди:
* `.venv` в обходе (чужие `install`/`discover` в нашей полке);
* псевдонимы импорта: `from lang.ru.lemma import install as _i` + `_i()` —
  вызов `install`; их четыре файла, а число было «ноль»;
* адреса из данных и динамические имена (Л1).

После починки и прогона: **полка-только-тесты 20, под-вопросом 4, мёртво 19**.

### Л3. «Код смотрит на `curiosity.threshold_exceeded()`» — такого метода нет

Выдумано. Решение «искать» принимает `verdict.ok`, дальше `note_unknown` +

### Л4. «`core/adapter.py` — хлам, удалять» — неверно

Тест изоляции памяти **исполняет** адаптер (`TeacherToStorageAdapter()`,
`save_for_storage()`), а не только читает путь. Это отсоединённый конвертер
формата мира, работающий только из-под теста.
