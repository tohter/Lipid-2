# п.A — ПОРЯДОК КАТЕГОРИЙ: ЗАМЕРЫ И ИТОГ

Задача из очереди: «категория, которой отвечают на „что такое X“, обязана
выбираться СОДЕРЖАНИЕМ, а не алфавитом Вики и не порядком записи».

Постановка оказалась неверной. Ниже — почему, на числах.

---

## ЗАМЕР 1. Где выбор категории вообще решает ответ

Ведущий путь ответа (`_definition_answer`): `definition > hierarchy[0] >
properties`. Прогнал реальные функции канала и мозга по 22 живым словам
снимка `wiki_category_snapshot.json` + `wiki_lead_snapshot.json`:

| | слов |
|---|---|
| ответ определяет `definition` | **22 из 22** |
| ответ определяет выбор из категорий | **0 из 22** |

Порядок категорий решает ответ только у сущностей, пришедших **не из Вики**:
в `lipid_world.json.pre-clean` — 3 из 6 сущностей
(«флюгер»: измерительные приборы/механизмы/объекты; «кошки»; «луга»).

## ЗАМЕР 2. Порядок API — алфавит (подтверждён)

`p26b_wiki_noise.py`, 172 уникальные категории 22 слов: у **19 из 22** первая
видимая категория = алфавитно первая. Утверждение из прежнего докстринга
(«Вики идёт от абстрактных к конкретным») — ложь, подтверждено обратное.

## ЗАМЕР 3. Гипотеза «род из графа родителей категорий» — ОПРОВЕРГНУТА

Снято (`pA_parents.py` → `wiki_parents_snapshot.json`): родители всех 172
категорий. Граф настоящий: `кошки → Домашние животные, Кошачьи, Фелинология`;
`собаки → Домашние животные, Псовые`.

Правила-кандидаты сверены (`pA_rank.py`) с золотом — родом из первой строки
статьи, выбранной РЕДАКТОРАМИ Википедии (не мной). Слов с золотом и выбором
из ≥2 категорий — 5:

| правило | совпало с золотом |
|---|---|
| `as_is` (алфавит, как было) | 1 из 5 |
| `reverse` | 1 из 5 |
| `spec` (у кого больше кандидатов-предков) | 1 из 5 |
| `spec+shared` | 1 из 5 |

Причина: категории Вики отвечают на «X **принадлежит** множеству C», а не на
«X **является** C». Собака ∈ {волки, животные-компаньоны, космополиты};
ни одно множество не является её родом, и обход графа этого не изменит.

## ЗАМЕР 4. Порядок иерархии локального Учителя

Промпт (`teacher1.py:430`) обещает `hierarchy[0]` = ближайшее семейство,
`hierarchy[-1]` = корень. Проверки не было НИКАКОЙ. Прогнал (`pA_llm_order.py`,
Gemma @8080, изолированная память):

* **конец** списка держится: 16 слов из 17 заканчиваются «объекты/абстракция»;
* **начало** не держится: первый элемент совпал с золотом **2 из 7 (29%)** —
  «вода» → «жидкости» (золото: химическое вещество), «машина» → «транспортные
  средства» (золото: техническое устройство).

Вывод: на этом порядке ответ тоже строить нельзя. Отдельный дефект: контракт
промпта нигде не проверяется — тест на него не написан, очередь.

## ЗАМЕР 5. Слияние каналов переставляет ответ

`merge_entity` добавляет без повторов ⇒ порядок = порядок вызова каналов.
Замер на «флюгер»: локалка→Вики даёт `[0]=«метеорологические приборы»`,
Вики→локалка — `[0]=«измерительные приборы»`. Буквально «кто ответил раньше».

## СЛЕДСТВИЕ, ИЗ КОТОРОГО СДЕЛАНА ПРАВКА

Первую категорию нечем сделать «правильной» — правильного рода в данных нет.
Значит выдавать её за род нельзя. **`_definition_answer` перестал выбирать
одну категорию и начал перечислять известные множества:**

```
было:  «Валенок — это вещь (категории: вещь -> обувь).»   ← род выдуман
стало: «Определения у 'валенок' нет; известно, что он
        относится к: вещь, обувь.»                        ← что реально есть
```

Одиночная категория отвечает по-прежнему («X — это Y»): там выбирать нечего,
одна категория — это единственное мнение, а не алфавитная позиция.

Замок `TestOrderOfRecordingChoosesTheAnswer` был написан «зелёным, покраснеет
при починке» — он покраснел и переписан вместе с новым правилом (3 теста,
все с числами этого дока). Мутации: откат к «первая = род» → падают 2 теста.

## НАЙДЕНО ПО ПУТИ (и починено)

Ведущий путь ответа — `definition`, и он оказался **невидимым для замеров
раньше**. Живой прогон дал:

```
«Флюгер — крыло) — метеорологический прибор…»
```

Причина: `strip_self_name` искал связку « — » первым вхождением, а оно живёт
внутри этимологической скобки `(нид. Vleugel, нем. Flügel — крыло)`. Скобки
теперь маскируются (`_bracket_spans`), связка ищется вне их. Языковой список
префиксов («лат.», «нем.»…) НЕ докупался: замер по снимку лидов дал 0 новых
случаев, а маскирование скобок закрывает класс целиком.

Замер после правки: **0 дефектов из 22** (был 1 — «флюгер»; пограничный
«дом» — лида «Жилище, жильё — …», перенаправление статьи, — остался как
есть: называть себя именем перенаправления честнее, чем выдумывать связи).
Путь общий с
ответом пользователя — чинится не только Вики.
