# Задача 32: РАЗДЕЛЕНИЕ СТАТИКИ И СОБЫТИЙ ПРИ ИЗВЛЕЧЕНИИ (шаг A из п.29)

## СТАТУС: СДЕЛАНО (см. memory.txt [ЗАДАЧА 32])

## Постановка (ДО правки)

Разрыв A: экстрактор (`core/extract.py`) выдаёт ФАКТЫ, а рассказ содержит ещё
и СОБЫТИЯ. Симулятору нужны события (порядок во времени), а класть их некуда:
сейчас `sim.add_event(...)` вызывается РУКАМИ в `build_*_simulator`.
Границу «кошка ЕСТ птиц (факт)» / «кошка СЪЕЛА канарейку (событие)» проводит
человек.

## ПРОВЕРКА ПАМЯТИ (сделана ДО правки, команды)

  $ grep -n "CAUSES" core/extract.py     -> НЕТ НИ ОДНОГО СОВПАДЕНИЯ
  $ grep -oE '"[A-Z_]+"' core/extract.py -> CAUSES отсутствует в списке

  ЗНАЧИТ, запись в memory.txt п.29 «core/extract.py даёт CAN_DO/OBJECT_OF/CAUSES»
  НЕВЕРНА: экстрактор CAUSES не порождает. Порядок «схема -> извлечение»
  остаётся верным, но CAUSES придётся извлекать с нуля, а не «уже есть».

## Решения

1. **Различие статика/динамика — грамматическое, не смысловое.**
   Факт: связка/прилагательное/модальность/общее настоящее («кошки едят птиц»).
   Событие: личный глагол в ПРОШЕДШЕМ времени или совершенном виде —
   «кошка съела канарейку» произошло в конкретный момент рассказа.

2. **Событие НЕ пишется в онтологию.** У него своя секция в мире —
   `"events"`: subject / action / object / order / tense / evidence.
   Онтология (entities/observations) по-прежнему только про «что есть».

3. **Порядок во времени — из порядка предложений.** Рассказ читается по
   предложениям; order события = номер предложения, где оно встретилось.

4. **Симулятор читает события ИЗ МИРА, а не из рук.** `build_*_simulator`
   больше не вызывает `add_event` вручную — он загружает секцию `"events"`.

5. **Учитель учит ФАКТАМ, события размечает текст.** (Правило п.29 сохранено.)

## Критерий готовности

  * Экстрактор помечает факт/событие признаком (predicate=event|fact), а
    Learner пишет события в секцию `"events"` мира.
  * `build_fire_rain_simulator` / `build_cat_canary_simulator` собирают рассказ
    из секции `"events"`, вручную ничего не добавляют.
  * Ответы симуляторов НЕ меняются (эталон задачи 31 держится).
  * Рассказ «кошка и канарейка» целиком (5 предложений) разбирается из JSON.
  * Замер: сколько предложений дали событие, сколько факт; тест на границу.
  * 353+ тестов зелёные.
