# СТРУКТУРА ПРОЕКТА LIPID-2 — карта модулей

Проект разделён на слои. Правило границы языка: `core/` не знает русского,
русский живёт в `lang/ru/`, а мост к нему — `brain/`.

```
run.py ──> ui/app_gui.py (окно) ──> ui/presenter.py (логика окна без Tk)
              │
              ▼
        brain/lipid2_brain.py  (КОГНИТИВНЫЙ ОРКЕСТРАТОР — мозг, «кто что решает»)
              │
    ┌─────────┼─────────────────────────────┐
    ▼         ▼         ▼                   ▼
 learner   thinker   framefiller        simulator
 (учитель) (думалка) (думалка-каркас)   (симулятор)
    │         │         │                   │
    ▼         ▼         ▼                   ▼
  teachers/  lang/ru/  core/  <-  нейроморфное ядро (граф, SDR, морфология)
```

## СЛОЙ 2 — МОЗГ: `brain/` (кто решает, что спросить и ответить)

| модуль | что делает |
|---|---|
| `brain/lipid2_brain.py` | **Когнитивный оркестратор.** Связывает всё: Учитель (каналы знания), думалка, симулятор, гормоны. Отвечает на «что такое…», «может ли…». |
| `brain/learner.py` | **УЧИТЕЛЬ.** Обучение из текста: предложение → факты → граф. Правила: не перезаписывать, не выдумывать сущность, помнить происхождение. |

| `brain/framefiller.py` | **ДУМАЛКА-КАРКАС (кирпич 5).** Из набора понятий заполняет ролевой каркас (предикат/субъект/объект/место/время) как СЕЛЕКТОР по базе. |
| `brain/question.py` | Разбор вопроса шаблонами. |
| `brain/curiosity.py` | Кортизол как флаг поиска, дофамин как право записи (любопытство). |
| `brain/simulator.py` | Симулятор (черновик): события рассказа, предсказания. |
| `brain/social_sim.py` | Социальный симулятор: ожидания, их нарушения, эмоции. |
| `brain/emotions.py` | Слой эмоций симулятора (черновик, лёгкая симуляция). |
| `brain/sleep.py` | Цикл сна: опыт получает право понижать вес связей. |
| `brain/storyload.py` | Витрина рассказов: найти мир на диске, подобрать симулятор, спросить. |

### УЖЕ ЕСТЬ — СОЦИАЛЬНЫЙ ДВИЖОК (НЕ ИЗОБРЕТАТЬ ЗАНОВО)

Это «мозг ребёнка»: движок социальной динамики для рассказов про отношения.
Он РАБОТАЕТ и отвечает на «почему кошка сожрала канарейку» цепочкой
«нарушение доверия -> обида -> гнев -> агрессия». Проверено живым прогоном.

| модуль | что уже умеет (измерено) |
|---|---|
| `brain/emotions.py` | Две независимые шкалы 0..255 (любовь и ненависть живут вместе). Близость уже МНОЖИТЕЛЬ заряда. Эмоция — процесс во времени: attack/decay/pending, пол покоя, порог bad_at_least для действия. |
| `brain/social_sim.py` | Ожидания (`Expectation`), нарушения (`Violation`), схема-цепочка «нарушение->предательство->обида->гнев->агрессия». `Expectation` выводится ИЗ ТЕКСТА: «попросила не рассказывать тайну» -> holder/target/action/negated. Близость/доверие — ПОПАРНЫЕ РЁБРА `RelationState{closeness, trust, confidence, provenance, sources}`, выведенные из текста словарём-признаками + правилом-суммой (провенанс «вывод по правилу»); глобальная константа ЗАМЕНЕНА. |
| `brain/storyload.py` | Витрина миров с диска: `handler` из схемы выбирает класс симулятора (`Simulator` для «огонь», `SocialSimulator` для «социум»), рассказ подтягивается по `script`-директивам. |
| `brain/simulator.py` | События рассказа, снимки эмоций, вопрос через схему (`why_acted`/`why_stopped`). |
| `brain/question.py` | `ask_story(text, sims)` — ответ на свободный вопрос, маршрутизация по схемам. |

Миры и рассказы — данные на диске: `experiments/cat_canary_world.json` +
`experiments/cat_canary_story.json`. Схема `social_betrayal` и абстракции
(доверие, предательство, обида, гнев, агрессия) — уже есть как сущности мира.

**ВАЖНО для следующих сессий:** эмоции и социальный симулятор были написаны
раньше и не использовались в живом пути (`brain/lipid2_brain.py` их не зовёт).
Не изобретать заново. СДЕЛАНО 14.11: вертикальный срез вывода близости/доверия
встроен в `social_sim.py` (словарь-признаки + правило-сумма, провенанс),
попарные рёбра `closeness(A,B)`/`trust(A,B)` живут в симуляторе, в БД НЕ
пишутся (см. `consult/близость_консультация_вывод.md` и
`tests/test_closeness_derive_contract.py`). ШАГ 4 (14.11): доверие дают и
глаголы-акты `{доверить, довериться, доверять, вверить}` — не только просьба;
«рассказать/разболтать» намеренно вне набора (шаг 5, предательство).

## ГЛАВНЫЙ ЗАКОН ПРОЕКТА

**Глагол/роль вопроса обязан участвовать в пути. Заведомо ложные связи в базу
не писать.** Думалка — селектор по базе, а не генератор; у неё нет источника,
из которого можно «придумать» слово.
