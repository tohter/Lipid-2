# ЛИПИД-2: ЧТО УЖЕ УМЕЕТ

*составлено 04.11.2026. Числа витрины снимает измерением `tools/presnum.py`; правь инструмент, а не цифру глазами*

---

## 0. В чём вообще идея

Вместо языковой модели — **причина**. Трансформер предсказывает слово; Lipid-2
строит граф связей, предсказывает **следствие** и умеет объяснить, **почему**.

| чем НЕ является | чем является |
|---|---|
| чат-обёртка над LLM | граф знаний + предиктивный цикл на бинарных векторах |
| LLM как рассуждатель | LLM/Вики/пользователь как **три внешних учителя**, отключаемых галочкой |
| «знания в весах» | знания в JSON, который читается глазами (`data/memory/lipid_world.json`) |

Мозговое ядро — `core` + `brain`; размеры, число тестов и файлов витрина
снимает измерением, а не помнит сочинёнными (блок «Цифры»). LLM в ядре нет
ни на одном шаге рассуждения.

## 1. Слой слова: понимает форму, а не строку

```
"свойства флюгера"  ──LemmaResolver──>  узел "флюгер"
"о кошке", "кошкой", "кошки"        ──>  тот же узел
```

* SDR-1024: эмбеддинг → ровно **20 активных бит** (2%), детерминированно.
* узнавание порогами, которые **измеряет сам граф**, а не выставил человек;
* шумовой пол ~10 бит и НЕ растёт с размером графа (500 → 15000 узлов);
* ложных узнаваний **0.0%** на 15 000 узлов (пропусков 25% — осознанно:
  пропуск = дешёвый звонок учителю, ложное «узнал» = тихая ложь).

**Ограничение (известно):** MiniLM-L12-v2 слеп на часть синонимов
(холостой~неженатый 0.47). Бинаризатор это не чинит, лечится LaBSE/ruBERT.

## 2. Слой знания: текст → причинные связи (без единого вызова LLM)

```
"Кошка ловит мышь"  →  кошка --CAN_DO--> ловить
                       ловить --OBJECT_OF--> мышь
                       СОБЫТИЕ (кошка, ловить, мышь, прош.вр.)
```

Отношения объявлены в реестре `core.storage.RelationType` — витрина печатает
его список, а не помнит наизусть:

<!--presnum:relations-->
```
`IS_A / HAS_PROPERTY / CAN_DO / SYNONYM_OF / CAUSES / IS_ROLE / LOCATED_IN / OBJECT_OF / PART_OF / INSTRUMENT / RECIPIENT / PURPOSE / ABOUT / HAS_PART / CIRCUMSTANCE / CONDITION / VALUE`
```

Раньше здесь лежал список короче реестра, и длина его не выдавала: сверяться
стал сам перечень, а не число рядом с ним.

Правило: **падеж + предлог задают роль, порядок слов — нет.**

Что реально разобрано и закреплено тестами:

| вход | что происходит |
|---|---|
| «Кит — это **не** рыба, **а** млекопитающее» | рыба не становится связью; отрицание помечено, вес /3 |
| «Билет стоит **5000 рублей**» | `билет --VALUE--> 5000 рублей`, мера и разряды |
| «Мяч, **который бросил мальчик**, укатился» | разобран по частям: `мяч→укатиться`, `мальчик→бросить→мяч`; «который» **не** засоряет онтологию |
| «Кошка спрятала мышь, **чтобы не** ловить её» | `спрятать --PURPOSE /НЕ/--> ловить`; «не» остаётся в своём предложении |
| «бегемот, **или** гиппопотам» | второе имя прикрепляется к той же сущности |

Омонимы решаются **синтаксисом**, а не частотой словаря. Не смог разобрать —
**пишет в notes**, а не выдумывает правдоподобную связь.

## 3. Три независимых канала знания

```
неизвестное слово ──> [1] Gemma @8080  ──┐
                    [2] Википедия       ──┼──> merge_entity ──> Вселенная
                    [3] «спроси меня»   ──┘        (единственная точка слияния)
```

* каждая галочка — **свой** канал, гасится независимо;
* бюджет обращений **виден**: «обращений к Учителю: 3 из бюджета 3» + явная
  строка «лимит: 8 слов не спрошено»;
* сливается по **одному** правилу `merge_entity`, под транзакцией — фоновое
  обучение не затирает ответ пользователя.

## 4. Опыт ≠ онтология: два разных числа

Главный архитектурный запрет этой ветки: цикл предсказания **не имеет прав
записи** во Вселенную. Ни узлов, ни фактов, ни веса онтологии.

```
 онтология (вес ребра, уверенность)     опыт (сила перехода 0..15)
        learner                                 cortex
            └────────── сверка ──────────┘
                         ↓
   «онтология утверждает, опыт не подтвердил»  (weight≥150, сила≤3)
   «опыт есть, онтология молчит»               (сила≥8, нет CAN_DO)
```

Расхождение **виден пользователю**, а не спрятан в логах.

**SLEEP CYCLE** — единственный легальный мост «опыт → вес онтологии»:
порог **измерен** (80 тиков = 8 очков силы по 10 тиков на очко), consolidation +
decay + сверка с файлом. Порог не угадан: пустая консоль тоже сжигает опыт.

## 5. Объяснение «почему» из статики, не из LLM

```
brain/simulator.py:  « why прекратился пожар?»
                     вода --гасить--> огонь  ──> вывод из фактов графа
```

Ответ собирается из путей графа. LLM не участвует — иначе это была бы
правдоподобная имитация понимания.

## 6.GUI и наблюдаемость

* вкладки: обучение, вопрос, инспектор опыта, **Сон**;
* журнал с копированием по ПКМ, обратный вопрос «а что ты знаешь о X»;
* гормоны (норадреналин/кортизол) показывают **состояние**, а не только текст;
* метрики = числа **сеанса**, а не пожизненная сумма; инвариант арифметики
  `hits + misses + no_expectation == ticks` проверяется на каждом прогоне.

## 7. Честность как инженерная норма (то, что отличает этот проект)

Здесь это не лозунг, а механизм. Правила, вшитые в код и тесты:

1. **Молчаливая деградация = баг.** Нет numpy → баннер, а не тихий
   символьный хэш. Нет pymorphy3 → `available=False` в отчёте.
2. **Каждый порог имеет ЗАМЕР.** Тесты, пороги, шумовой пол, шаг сна — всё
   из `experiments/RESULTS.md`, «по теории» запрещено. Витрина чисел не
   помнит: она их снимает (`tools/presnum.py`), а тест не даёт вписать
   число, которое нечем померить.
3. **Пустой ответ ≠ правдоподобный ответ.** «Экосистема — это экосистемы»
   считалось успехом; теперь это отказ, который зовёт учителя.
4. **Отказ обязан называть известное.** Если про кошку известно только
   «пушистая» — система говорит это, а не «ничего не знаю».
5. **Мутационное тестирование с проверкой применимости шаблона.** Тест,
   который не краснеет от поломки, ничего не охраняет.

## 8. Чего НЕ умеет (тоже измерено)

| не умеет | цена |
|---|---|
| «где живёт мышь», если в памяти есть «мышь живёт в норе» | интент UNKNOWN |
| «Дом, где жил пёс, сгорел» → связь места с событием | `LOCATED_IN` не пишется |
| «чтобы не **есть**» — глагол «есть» | проглотирован стоп-листом связки |
| обратный порядок слов: «Огонь гасит вода» | объект → «вод» (омоним род. п.) |
| придаточное **без** запятой: «Дом где жил пёс сгорел» | честная заметка вместо связей |
| категория-ответ из Вики | **первая категория больше не выдаётся за род**: перечисляются множества, к которым предмет относится. С одиночной категорией (7 слов из 22) алфавит пока побеждает |
| идиомы и метафоры | отложены сознательно |

Последняя строка разобрана измерением (23.10, `experiments/ORDER_TASK.md`) и
оказалась **не про порядок**, как думалось. Порядок категорий по содержанию
вывести НЕКУДА: категории Вики отвечают на «X принадлежит множеству C», а не
на «X является C» — четыре правила порядка из графа родителей категорий
совпали с эталоном 1 раз из 5, ровно как алфавит. Поэтому систему перестали
заставлять врать: вместо выдуманного рода она называет то, что знает.
Ранжировать по частоте подтверждений нельзя — грубая категория подтверждается
чаще именно потому, что она грубая.

## 9. Граница языка: ядро не знает русского

Правило, запертое отдельным замком (`tools/langborder.py` и
`tests/test_langborder_contract.py`):

```
текст -> lang/<xx> -> IR-НА-ВХОД -> core -> IR-С-ВЫХОДА -> lang/<xx> -> текст
```

`core` обязан знать ТОЛЬКО IR. Русский для него — чужие байты; всё, что знает
падежи, предлоги и окончания, живёт в `lang/ru`.

Почему это витринное утверждение, а не деталь реализации: до разделения ядро
нельзя было переставить на другой язык, и молчало оно об этом ровно так же, как
молчит список в документе. Считает AST, а не grep: grep по слову «morph»
считает докстринги, комментарии и строки сообщений, то есть путает «код дёрнул
русский модуль» с «в докстринге упомянули русский модуль».

Три числа границы стоят в блоке «Цифры»: швов языка внутри ядра, файлов ядра со
следами языка и русских литералов в `core`. Трещотка асимметрична намеренно:
любое из этих чисел МОЖЕТ упасть без вопросов, РАСТИ не может — рост это
падение теста.

Честно об остатке: ноль швов означает «ядро не импортирует язык», а не «ядро
никогда не видело русского». Следы языка в ядре названы числом, а не обещанием.
Русские литералы в `core` считаются отдельной мерой именно поэтому: пока их
сотни, фраза «ядро языконейтрально» обязана оставаться незакрытым долгом, а не
победным отчётом.

## 10. Цифры

Сняты `tools/presnum.py` сегодня, а не переписаны с прошлого экрана. Правка
одной цифры руками запрещена тестом: блок перегенерируется целиком
(`.venv/bin/python tools/presnum.py --fix`), а число, для которого нет
измерителя, в блок не вписывается физически.

<!--presnum:numbers-->
```
тестов всего:                  959
контрактных тестов:            936
файлов с тестами:              59
файлов контрактных тестов:     54
отношений в реестре:           17
отношений у экстрактора:       16
отношений дошло до мира:       15
шов языка внутри ядра:         0
файлов ядра со следами языка:  3
русских литералов в core/:     163
методов ядра с русским выводом: 6
файлов языка в lang/:          5
строк в core/:                 8 636
строк в brain/:                5 628
строк ядра (core+brain):       14 264
строк в tests/:                18 320
строк Python всего:            43 957
файлов Python всего:           137
```

Отношений объявлено больше, чем умеет экстрактор, а до мира доходит меньше,
чем умеет экстрактор, — оба разрыва названы, а не сложены в одно число.
Разрыв 16 → 15 — цена конвейера: `INSTRUMENT` и `RECIPIENT` экстрактор вынимает
из фразы, но падежная роль события не становится знанием, и в мире эти имена
не появляются вовсе. Обратный разрыв тоже есть и он честный: `IS_A` доходит до
мира, хотя экстрактор его не порождает, — иерархию создаёт сам `learner`
(«ловить» → действие). Поэтому эти два множества НЕ вложены друг в друга, и
сводить их к одной цифре нельзя.

«Шов языка внутри ядра: 0» означает «ядро его не импортирует», а не «языка
больше нет»; остаток стоит двумя строками ниже.

Что числом не выражается, но тоже проверено:

* статикой запрещены мёртвый код, заглушки и write-only атрибуты
  (`tests/test_static_hygiene.py`);
* живая память за прогон не меняется — замеры пишутся только в `/tmp`
  (`tests/test_memory_isolation_contract.py`).

Раздел «почему» (раздел 5) проверен живым прогоном: «почему прекратился пожар?»
→ «потому что вода гасит огонь», вывод собран из `HAS_PART / IS_A / CAN_DO /
OBJECT_OF` учебного мира, LLM не участвовал.

## 11. Как проверить за 5 минут

```bash
LIPID2_STATUS=0 .venv/bin/python -m unittest discover -s tests
LIPID2_STATUS=0 .venv/bin/python tools/clean_world.py --check     # ЧИСТО
LIPID2_STATUS=0 .venv/bin/python tools/presnum.py --check          # витрина
LIPID2_MEMORY_DIR=/tmp/m .venv/bin/python run.py                  # GUI
```

Первая команда — полный прогон. Сколько в нём тестов, витрина не повторяет:
число живёт в одном месте, в блоке «Цифры». `--check` краснеет, если сегодняшняя
витрина разошлась с сегодняшним замером.
