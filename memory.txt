[ОБЗОР ПРОЕКТА]

Цель: автономный нейроморфный AI-движок Lipid-2 на разреженных бинарных
векторах (SDR-1024), предиктивном кортикальном ядре, графе знаний и
гормональной саморегуляции.

Принцип: отказ от трансформеров в ЯДРЕ для рассуждений. Локальная LLM —
внешний эксперт для bootstrap неизвестных концептов. Ядро использует ОДНУ
small-эмбеддинг-модель как СЛОЙ КОДИРОВАНИЯ senses -> bits (без семантики в
битах предиктивный цикл оперировал бы шумом).

[SDR СЕМАНТИЧЕСКИЙ] (core/encoder.py, коммит b11f7b7)

Раньше SDR1024 строился буквенным хэшем — сигнал был ПЕРЕВЁРНУТ (overlap
несвязанных слов выше синонимов), и все пороги на нём были ложью.

Сейчас: paraphrase-multilingual-MiniLM-L12-v2 (CPU) -> 384 float;
вычитание среднего по калибровочному корпусу (обязательно: у мультиязычных
эмбеддингов крайняя анизотропия); top-k по 1024 случайным гиперплоскостям
(RPP), k=20 -> ровно 20 бит. Детерминированно (фиксированный seed, калибровка
data/memory/sdr_calibration.pkl, 23 МБ, regenerable, .gitignore). Инвариант:
1024 бита, ровно 20 активных (~2%). API SDR1024 не менялся.
cfg-хэш кодировщика d39733936ebd пишется в meta; при несовпадении — явное
предупреждение (би́ты вне своего кодировщика бессмысленны).

ЗАМЕРЫ (полная таблица — experiments/RESULTS.md):
  * Шумовой пол ~10 бит и НЕ растёт с размером графа (500 -> 15000 узлов).
  * Пороги (core/cortex.py): UNKNOWN_CEILING=13, KNOWN_FLOOR=17,
    HIT_THRESHOLD=13; unknown_threshold()=clamp(шумовой_пол+4, 13, 17) —
    адаптивно, пол измеряет САМ ГРАФ (SdrIndex.self_probe_floor()), пересчёт
    каждые 64 тика.
  * Порог 13: ложных узнаваний 0.0% на 15 000 узлов, пропусков 25%. Асимметрия
    осознанна: ложное «узнал» = LLM не позван = тихая ложь; пропуск = лишний
    звонок LLM, дёшево.
  * Порог 20 битами не улучшить: ограничивает КАЧЕСТВО эмбеддинг-модели.

ОПАСНАЯ ДЕГРАДАЦИЯ ГРОМКАЯ (core/encoder.py:_warn_letterhash): нет numpy ->
откат на LetterHashEncoder, баннер в stderr + строка в чате GUI при старте.

[УЗНАВАНИЕ ФОРМ СЛОВА] (core/lemma.py, LemmaResolver)
«свойства флюгера» -> узел «флюгер». На FLOAT-эмбеддингах, НЕ на битах SDR
(на 20 битах морфология неразличима). COS_THRESHOLD=0.85, ключ = первые 3
буквы нормализованного стема. Замер: 22/24 формы, 1.0% ложных схлопываний на
8000. Резолвер ТОЛЬКО ЧИТАЕТ (узлы не сливаются). Инициализируется лениво.

[КОМПИЛИРУЕМОЕ ЯДРО (C/C++) — ДОГОВОРЁННОСТЬ И ЗАМЕРЫ]

Итоговую программу планируется писать на компилируемом языке (пользователь —
ассемблерщик/PLC). Пороги (13/17 pools, шумовой пол) ОТ ЯЗЫКА НЕ ЗАВИСЯТ.

ЧТО УЖЕ «КОМПИЛИРУЕМО» ПО ПРИРОДЕ (замерено):
  * SDR: 16 слов uint64 = 128 байт; overlap = AND+popcount, 3.03 мкс/узел
    numpy/x86 (20 000 узлов за 0.061 с).
  * Граф в битах: 128 байт/узел; Python-обвязка — 9.79 КБ/узел дельты RSS
    (1.3% знание, 98.7% интерпретатор). В C соотношение обратное.
  * Предиктивный цикл, STDP, гормоны, адаптивный порог — арифметика целыми.

ДВА РЕСУРСОЁМКИХ СЛОЯ (оба НЕ ядро):
  * MiniLM-L12-v2 мультиязычная: 449 МБ весов, инференс 15.4 мс/слово CPU.
  * pymorphy3 + dicts-ru: 46 МБ.
  * sdr_calibration.pkl = 47 МБ (float32-эмбеддинги 30 055 слов = 44 МБ); в
    SDR те же слова 3.7 МБ. Для компилируемого ядра нужен КЭШ БИТ, не float.

ГРАНИЦА:
  OFFLINE-ФАБРИКАЦИЯ (Python, за пределами устройства): обучение, Учитель,
  извлечение фактов, морфология, калибровка, замер порогов. Результат —
  компактный бинарный образ: веса кодировщика (нужные языки), таблица SDR
  известных слов, таблица «форма -> лемма+граммемы» только для нужных слов.
  ОНЛАЙН-ЯДРО (C, без Python): SDR, граф, overlap-ранжирование, предиктивный
  цикл, гормоны. Вход — слова и биты, выход — связи и решения.

ЖЕЛЕЗО (цифры честные): ядро 128 байт/узел -> 1000 узлов = 128 КБ + синапсы:
в ESP32 (520 КБ RAM) да; в Arduino Uno (2 КБ RAM) НЕТ физически. Кодировщик
449 МБ не влезет никуда — на МК только кэш бит. «1-2 мкс/узел на ESP32» — НЕ
замер, а прикидка; как порог не использовать.

ПРАВИЛА КОДИРОВАНИЯ ПОД C (действуют уже):
  1. ФОРМАТ ДАННЫХ = КОНТРАКТ: фиксированные ширины целых, little-endian,
     длины перед массивами, UTF-8, никаких pickle в переносимой части.
  2. Имя узла/связи остаётся ТЕКСТОМ, не id словаря Python.
  3. Пороги читать из образа с cfg-хэшем, не зашивать в код.
  4. Никаких torch/numpy в ОНЛАЙН-части.
  5. Ключевые алгоритмы (overlap, ранжирование, цикл) — с поштучной проверкой
     на целых, чтобы перенос в C проверялся сверкой таблиц, а не «на глаз».

[ОБУЧЕНИЕ ИЗ ТЕКСТА] (core/morph.py, core/extract.py, brain/learner.py)

core/morph.py — MorphAnalyzerFacade над pymorphy3. parse_all -> ВСЕ варианты;
  кандидатов фильтрует СИНТАКСИС (согласование + известность леммы), а не
  частотный словарь (parse()[0] неправилен на омонимах). Граммемы нормализованы.
  role_from(): NOUN/NUMR->subject, ADJF/ADJS/COMP->property, VERB/INFN/PRTF/GRND->
  action, стоп-слова->stop. Числа цифрами получают POS=NUMR вручную
  (_NUMERIC_RE), иначе выпадают. Нет pymorphy3 -> эвристика + available=False в
  отчёте.

core/extract.py — SimpleExtractor: детерминирован, оффлайн, БЕЗ LLM. 13 отношений
  (IS_A/IS_ROLE, HAS_PROPERTY, CAN_DO, LOCATED_IN, OBJECT_OF, PART_OF, INSTRUMENT,
  RECIPIENT, PURPOSE, ABOUT, CONDITION, CIRCUMSTANCE, HAS_PART, VALUE).
  ПРАВИЛО: ПАДЕЖ + ПРЕДЛОГ задают роль, ПОРЯДОК СЛОВ — нет. Местоименный актёр
  ГАСИТ CAN_DO полностью. Отрицание не порождает положительную связь (negated,
  вес /3). Прилагательное -> ближайшему согласованному существительному.
  VALUE: числительные словами/цифрами + мера («5000 рублей», множители-разряды);
  без числа и единицы VALUE не выдумывается. Уверенность 0.45+0.4*score Ronin,
  ×0.8 на неоднозначности, потолок 0.95.

brain/learner.py — Learner.learn_from_text(text, source, allow_teacher).
  Зависимости — только функции в конструкторе, поэтому тесты не тянут LLM.
  replay_observations(): связи из рассказов восстанавливаются при старте мозга.
